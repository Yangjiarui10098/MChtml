## 详细更新记录

### v0.1（初版）
- 上线单页下载站：粒子背景、方块 Logo、悬浮动画。
- 提供 Windows / Android / iOS 三个平台的下载入口弹窗。
- 支持中英文切换（手动按钮）。

### v0.2
- 新增页脚签名区：「用爱打造 / © 2026 我的世界下载中心」。
- Android 下载链接由移动端独立入口统一为官网首页入口。

### v1.0（大重构）
> 说明：从 v0.2 直接跳到 v1.0，是因为进行了整体大重构。

- HTML 语义化重构：改用 `<main>`、`<button type="button">` 等规范标签。
- 全面无障碍支持：弹窗加 ARIA（role="dialog" / aria-modal / aria-labelledby）、键盘焦点陷阱（trapFocus）、:focus-visible 焦点样式。
- 语言持久化：新增语言自动检测、localStorage 存储语言偏好。
- 页面补充 meta description（SEO）。
- 外链统一加 `rel="noopener noreferrer"`，下载项描述文案优化。

### v1.1
- 新增「打开指定网页」功能：独立弹窗输入网址，自动补全协议后打开。
- 首页按钮改为按钮组布局（下载 / 打开网页）。

### v1.2
- 网址自动补全增强：默认补全 `https://www.`。
- 裸二级域名（如 163.com）自动补 www；子域名（mail.163.com）与已带 www 的保持原样。
- URL 解析细化：分离主机名、端口、路径、查询与锚点。

### v1.3
- URL 解析健壮性强化：
  - 协议相对地址（//example.com）按 https 处理，避免生成 `https:////` 无效地址。
  - 仅允许 http/https，拦截 ftp 等其他协议。
  - 支持 IPv6 字面量（[::1]:8080）。
  - 主机名非空校验（拦截 `https://`、`https:///path` 等输入）。
- 错误提示加 `role="alert"`，辅助读屏播报。

### v1.4
- 打开网页后新增 Toast 提示：若无法访问提示「可能是网络限制，请科学上网后重试」。
- 主机名有效性校验：拒绝以点结尾、空标签、含非法字符的主机名（如 www.）。

### v1.5
- Google Fonts 字体源切换为国内可访问的镜像（fonts.loli.net），改善国内加载速度。

### v1.6
- 新增 www 子域探测：输入裸域名时，后台探测 www 子域是否存在，不存在则自动改用裸域打开。
- 打开按钮增加「检测中…」加载态。
- Android 下载入口文案与链接调整。

### v1.7
- 处理浏览器弹窗拦截：被拦截时保留弹窗并提示用户允许弹出窗口后重试。
- 改为在用户手势上下文内同步调用 `window.open`，规避 Safari/iOS 拦截。
- 后台探测 www 不可达时，将已打开的标签页重定向到裸域。

### v1.8
- 安全加固：改用 about:blank 同源句柄 + 手动置 `opener=null`，切断反向引用，消除 reverse tabnabbing 竞态窗口。
- 新增弹窗被拦截的中文提示文案。

### v1.9
- 弹窗增加 `aria-hidden`，背景滚动锁定（overflow: hidden）。
- URL 校验补强：IPv4 每段严格 0-255（拒绝 999.999.999.999）、端口 1-65535 纯数字校验。
- 探测请求加 5s 超时，慢网络不再无限等待。
- 打开按钮防连点：进入禁用、成功后 1.5s 恢复、失败立即恢复。
- 输入框支持回车提交，且忽略中文/日文输入法组词确认回车。

### v2.0
- 错误提示按语言键重渲染（setWebError / clearWebError），切换语言不再重置为默认文案。
- 支持非 ASCII 域名（如 中文.com），百分号编码后交由浏览器按 UTF-8/IDN 解析。
- 探测超时调整为 3s，且超时（AbortError）不再触发裸域回退，避免误伤慢站点。
- 焦点恢复逻辑重构，移除冗余的「检测中」文案。

### v2.1
- 页面新增免责声明：「非官方页面，与 Mojang / Microsoft 无关」。
- Android / iOS 下载项描述细化：手机版/平板（中国版）、iPhone/iPad（国际版）。
- 滚动锁改为计数器：多个弹窗可叠加锁定，全部关闭后才恢复滚动。
- 中文域名改用 Punycode 转换（URL 对象），修复误判问题。
- 无障碍增强：focusin 全局焦点陷阱、响应系统「减少动态效果」设置实时切换动画。

### v2.2（最新）
- 移除不可靠的 no-cors www 探测与裸域回退机制：该探测无法区分网络可达性与 HTTP 状态，误判可能把用户从正常站点踢走，改为直接补 www 打开，交由用户自行判断。
- 拦截 URL 中 `@`、`\`、`%` 等特殊字符（防止 userinfo 截断与跨协议歧义）。
- 安全加固：先开 about:blank 同源句柄 → 同步置 opener=null → 再导航，目标页从加载起就看不到 window.opener。
- 新增 `data-i18n-content` 国际化支持，补充页面描述双语文案。
